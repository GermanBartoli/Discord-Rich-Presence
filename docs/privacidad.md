# Política de privacidad

La extensión accede únicamente a las páginas de `music.youtube.com` para leer la canción o sección visible y mostrarla en la cuenta de Discord abierta en este equipo. Los datos se envían al conector local mediante Native Messaging y de allí al cliente de Discord de escritorio mediante IPC. No se envían a servidores propios ni se recopilan analíticas.

La preferencia de activación se guarda localmente en Chrome. La extensión no solicita credenciales de Google ni de Discord. Al desactivar la actividad se envía a Discord una orden para borrarla.

La información visible en Discord queda sujeta a la configuración de privacidad de la cuenta y a las políticas de Discord. Para consultas, usá la sección Issues del repositorio.
